# Installing and Updating Revit Tools

Use **This computer** to install or update Flow tools for an installed Revit year.

Workstation Manager offers releases approved by your office for that year.

---

## Checking for Updates

1. Open **This computer**.
2. Select **Check updates**.
3. Review the summary above the tabs and the **Revit tools release** column.

Checking reads the approved release information. It does not install an update.

| Message | Meaning |
|---|---|
| **Matches approved release** | The verified installed release matches the office approval. |
| **Update available: …** | A newer approved Flow tools release is available. |
| **Not installed — install …** | Flow tools are missing and an approved release can be installed. |
| **No approved release set** | The office has not approved a tools package for this Revit year. |
| **Installed—release not recorded** | Flow components were detected, but the installed package release has not been verified. |
| **Updates not checked** | No current update comparison is available. Select Check updates. |

**Files match** means that the installed files checked by Workstation Manager match the recorded tools release.

!!! note "An unverified release needs review"

    **Installed—release not recorded** does not confirm whether the tools are current. Review the add-in details and any installation error before assuming an update succeeded.

---

## Installing or Updating Tools

1. Save your work and close all Revit sessions.
2. Connect to the office network.
3. Open **This computer** and select **Check updates**.
4. Select the required Revit year.
5. Select **Install / update tools**.
6. Review and complete any confirmation or administrator prompt.
7. Review the completion message and the refreshed release information.
8. Open that Revit version and check that Flow loads correctly.

Repeat the process for other Revit years as required.

!!! warning "All Revit sessions must be closed"

    Close every Revit session before installing or restoring tools. Closing only the selected Revit year is not sufficient.

New tools installations use the current Windows account. Existing installations retain their user or machine-wide scope. A machine-wide change may require administrator approval.

---

## Reviewing Release Notes

**Preview update notice** lets you review the notice for the selected Revit year without installing an update.

Where a custom note has been saved for the approved year and release, it appears in the update notice.

### Editing a Note

1. Select the required Revit year.
2. Select **Edit Note**.
3. Enter the release information you want users to see.
4. Select **Save Note**.
5. Select **Preview update notice** to review it.

!!! info "Notes are shared"

    Saving a note changes the office release information for that Revit year and release. It requires write access to the release catalogue. Ask your office administrator if you cannot save a change.
