# Flow Workstation Manager

**Flow Workstation Manager** helps you review installed Revit versions, keep Flow tools and applications up to date, and check software information across office computers.

It connects to your office's shared Flow folder for approved releases and computer reports.

**Application:** **Flow Workstation Manager**

---

## When to Use Workstation Manager

Use Workstation Manager when you need to:

- check which Revit versions are installed on your computer
- install missing Flow tools for a supported Revit version
- check for and install office-approved Flow updates
- restore a previous Flow tools installation
- review software versions reported by office computers
- check whether background checks and report delivery are working

Workstation Manager is a standalone Windows application. Revit does not need to be open to review inventory or check updates.

!!! note "Flow updates and Revit updates are different"

    Workstation Manager installs approved Flow tools and applications. It does not install Autodesk Revit updates or upgrade project models.

## Updates Remain Your Choice

Automatic checks can notify you when an approved update is available. Checking for updates does not install them.

!!! warning "Close Revit before changing Flow tools"

    Close all Revit sessions before installing, updating or restoring Flow tools, including sessions for other Revit years.
