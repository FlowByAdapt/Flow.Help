# Flow Server

The **Flow Server** section contains guidance for connecting to, reviewing and administering Autodesk Revit Server content using the standalone Flow Server application.

Flow Server is opened from the Windows desktop or Start menu. It does not require Revit to be open for browsing and administration, although supported archive and upgrade workflows use installed Revit versions for processing.

---

## Application

### Flow Server

Browse and manage Revit Server projects, review recent activity, create verified project archives and coordinate model upgrades between supported Revit versions.

Flow Server brings the main Revit Server administration workflows together in one application, including:

- Connecting to Revit Server 2025, 2026 and 2027
- Browsing and searching project folders and models
- Reviewing recent project activity and model history
- Creating, renaming and moving server folders
- Locking and unlocking Revit Server models
- Archiving individual models or complete project folders
- Upgrading and publishing models through a managed workflow
- Deleting models or project folders when they are no longer required

---

!!! tip "Starting with Flow Server?"

    Enter the Revit Server address, select the required server version and select **Refresh**.

    Once the connection shows **Connected**, use **Browse** to locate the required project, folder or model.

!!! info "Review before changing"

    Connecting, browsing, searching and reviewing activity do not change Revit Server content.

    Actions that create, move, rename, lock, unlock, archive, upgrade or delete content must be started deliberately and require confirmation where appropriate.
