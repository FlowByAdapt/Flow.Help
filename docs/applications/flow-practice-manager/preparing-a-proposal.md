# Preparing a Proposal

Use **Proposals** to prepare and save a fee proposal against a shared project record.

## Start from a Template

1. Open **Proposals** and select **New proposal**.
2. Choose a template and select the shared project for the proposal.
3. Select **Start proposal**.
4. Review the project number, client and site details. For example, check that the selected record is for the kitchen and living area alteration at the correct site.
5. Edit the scope and fees to suit the job.

!!! info "Project details come from the shared record"

    When a proposal is linked to a project, its project, client and site fields come from the selected record. Use **Change project** if you picked the wrong job.

## Choose a Contact

Expand **Choose a shared contact**, search by contact name, client or email, and select the correct person. Select **Use contact in this proposal** to fill the contact name and email.

## Save and Resume

Select **Save draft** and wait for the saved confirmation. To continue later, reopen the draft from the proposal register.

## Troubleshooting

### I Can’t Find the Project

In **Choose a project**, search by project number, client or site. If the list shows **No matching projects**, try a shorter part of the client or site name. Select the matching record from the results before choosing **Start proposal**.

### The Proposal Shows the Wrong Client or Site

Expand **Change project** and select the correct shared project. Check the project number, client and site again before saving the draft.

### My Draft Didn’t Save

Keep the proposal open and read the message next to **Save draft**. If Flow reports that it couldn’t reach the local database, your edits are still on screen. Once the connection is available, select **Save draft** again and wait for the saved confirmation before leaving the page.
