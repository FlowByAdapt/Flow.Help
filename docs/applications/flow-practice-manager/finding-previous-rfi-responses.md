# Finding Previous RFI Responses

Use **Search library** in the RFI workspace to find reviewed questions, responses and their supporting documents.

---

## Search for a Similar Question

1. Open **RFIs** and select **Search library**.
2. Enter a term from the council request. For the sample alteration, try `smoke alarm`.
3. Use the **Project** filter if you know which job the response came from.
4. Open a matching result and read the question and response together.

If a search returns few results, try a shorter term or clear the project filter to search across jobs.

---

## Check the Source Before Reusing an Answer

Open the original request and relevant supporting documents from the result. Check that the earlier question, building details and referenced drawing revisions are relevant to the job you’re working on.

For example, a previous response may show how the team referenced smoke alarm locations on a plan. Use the current project’s drawings and revision in your response.

!!! note "Check acceptance on the original project"

    A reviewed library entry means the record has been checked against its sources. Look for recorded council acceptance on the original project if that matters to your review.

Return to **Project RFIs** to draft and save the response for the current project.
