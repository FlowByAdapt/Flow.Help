# From Proposal to Project

Use this walkthrough to prepare a proposal, record its acceptance and check the project before moving into delivery. The example is a fictional kitchen and living area alteration.

---

## Prepare the Proposal

Follow [Preparing a Proposal](preparing-a-proposal.md) to select the shared project and save a draft. Review the project details, scope, stages, fees and exclusions for the alterations.

!!! note "Acceptance and handover are still being checked"

    The acceptance and project setup steps in Practice Manager describe the intended workflow. The Revit steps below follow the existing Project Setup guide.

## Record Acceptance

1. Open the proposal the client accepted. If you issued a revision, check that the scope and fee match the client's acceptance.
2. Record the acceptance against that proposal.
3. Review any conditions or items that need to be resolved before starting project setup.

!!! tip "Check the accepted revision"

    Compare the proposal reference or issue date with the client's acceptance before progressing the job.

## Set Up the Project

Once the approval has been recorded and reviewed, use the accepted proposal to set up the project. The agreed fees and starting budgets carry into the project alongside the tasks.

## Check the Project Before Delivery

Open the project in Practice Manager and check it against the approved proposal.

| Check | What to confirm |
| --- | --- |
| Project identity | The project number, client and site identify the right job. |
| Stages and tasks | The work set up for delivery matches the scope the client approved. |
| Stage fees | The amounts match the accepted proposal. |
| Starting budgets | The budgets are in the right stages for tracking work as it progresses. |

For the sample alteration, if the client approved design only, check that working drawings and consent support are outside the authorised scope for this stage of the job.

If setup stopped partway through, check whether the project record or project folders already exist before trying again.

---

## Continue in Revit

If the job needs a Revit model, open **Flow → Project → Setup** in Revit.

1. Check the **Project Year**, **Project Number**, **Client** and **Location** in [Project Identity](../../project/project-setup/project-identity.md) against the Practice Manager record.
2. Select **Review Identity**.
3. For a new model, follow [Creating a New Project](../../project/project-setup/new-projects.md) to select a project profile and confirm the template.
4. If a model already exists, open it and select **Inspect Project**. Use the **Setup Overview** to see which items still need attention. See [Reviewing a Current Project](../../project/project-setup/current-projects.md).
