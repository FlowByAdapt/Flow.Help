# From Proposal to Project

Use this walkthrough to prepare a proposal, record its acceptance and check the project before moving into delivery. The example is a fictional kitchen and living area alteration.

---

## Prepare the Proposal

1. Enter the client, site and a short description of the alterations.
2. Set out the agreed scope, stages, fees and any exclusions.
3. Review the proposal before issuing it. Check that the project description and site details will still make sense to the team when the job starts.

## Record Acceptance

1. Open the proposal the client accepted. If you issued a revision, check that the scope and fee match the client's acceptance.
2. Record the acceptance against that proposal.
3. Review any conditions or items that need to be resolved before starting project setup.

!!! tip "Check the accepted revision"

    Compare the proposal reference or issue date with the client's acceptance before progressing the job.

## Set Up the Project

1. Start project setup from the accepted proposal.
2. Review the project details, including the project number, client and site.
3. Open the resulting project record and check that it reflects the accepted proposal.

!!! note "Continue in Revit when a model is needed"

    Use [Project Setup](../../project/project-setup/index.md) to create or review the Revit project. Check the **Project Identity** against the Practice Manager record before continuing.

## Check the Result

Find the project in Practice Manager and confirm that its project number, client and site are correct. If setup stopped partway through, check whether a project record or project folders already exist before starting setup again.
