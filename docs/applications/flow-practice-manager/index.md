# Flow Practice Manager

**Flow Practice Manager** helps you take a project from a fee proposal through to project setup.

Use this guide when preparing a proposal, recording a client's acceptance or setting up an agreed project for delivery.

---

## Start Here

[Getting Started](getting-started.md) shows where to find a shared project and open a proposal.

[Preparing a Proposal](preparing-a-proposal.md) shows how to start from a template, link the project and save a draft.

[From Proposal to Project](from-proposal-to-project.md) follows a sample alterations project from preparing the fee proposal through to checking the new project record and continuing in Revit where needed.

[Reviewing a Project](reviewing-a-project.md) shows how to compare recorded hours, budgets and remaining work during delivery.

[Preparing a Progress Claim](preparing-a-progress-claim.md) shows how to check the amount to claim this period and review the invoice draft.

[Responding to Council RFIs](responding-to-council-rfis.md) covers capturing council questions, checking the source and preparing responses.

[Finding Previous RFI Responses](finding-previous-rfi-responses.md) shows how to search the reviewed library and check the source before using an earlier answer.
