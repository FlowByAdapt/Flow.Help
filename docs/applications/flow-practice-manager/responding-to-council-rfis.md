# Responding to Council RFIs

Use **RFIs → Project RFIs** to capture council questions, draft responses and check them against the source documents.

---

## Choose the Project

In **Choose a project**, search by project number, client or site. Select the matching project and check the consent reference before adding questions.

---

## Add the Council Questions

In **Add questions and responses**, choose **Import Word or PDF documents** to pull questions from the council request. To enter a question directly, choose **Type or paste a question**.

Review the draft entries against the original request. Check the question numbers, subparts and wording so each response can be matched back to the correct question.

!!! note "Check scanned requests against the original"

    Text recognition can misread question numbers, dimensions and drawing references. Check those details against the original PDF before relying on the extracted text.

---

## Draft and Check the Response

In **Complete responses and check imported records**, open the relevant draft. Write the response and check that any supporting document links point to the material you intend to reference.

For the sample alteration, the council might ask for the location of a proposed smoke alarm. Check the question against the council letter, then reference the relevant drawing and revision in the response.

Save the workspace so you can return to the response and its references. When the response is ready, copy it for submission through your usual council channel.
