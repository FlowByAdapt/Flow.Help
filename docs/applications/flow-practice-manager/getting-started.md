# Getting Started with Flow Practice Manager

Use **Projects and Contacts** to find the job you’re working on. Open **Proposals** when you’re ready to prepare a fee proposal or pick up a saved draft.

---

## Find the Project

1. Open **Projects and Contacts**.
2. Browse by project year. Choose **All years** if you’re unsure when the job was created.
3. Search for the project and open the matching record.
4. Check the project number, client and site before using the record in a proposal.

!!! tip "Use the project number when names are similar"

    A client may have several jobs, or different jobs may share a similar site description. Check the project number to confirm you’ve selected the right record.

If the contact or project doesn’t exist yet, see [Adding Contacts and Projects](adding-contacts-and-projects.md).

---

## Open a Proposal

Open **Proposals** and select an existing draft from the register to continue working on it. If you’re starting a fresh proposal, select **New proposal** and follow [Preparing a Proposal](preparing-a-proposal.md).
