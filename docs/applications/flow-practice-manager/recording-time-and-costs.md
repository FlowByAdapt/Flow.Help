# Recording Time and Costs

## Add Time

Select the project and the stage or task you worked on. Enter the date and hours, and add a short description of the work so it can be understood at the next project review.

For the sample alteration, record time spent revising the kitchen layout against the design stage.

## Add a Cost

Select the project and relevant stage. Enter the date, amount and description from the supporting record. Check the entry against the receipt or supplier invoice before saving.

## Check Your Entries

Review the saved entries for the period. Check the date, project, stage and amount or hours, especially if you worked on several jobs that day.
