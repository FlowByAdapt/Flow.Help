# Recording Time and Costs

Open **My work → Time and costs** to record a week of work and enter project costs.

---

## Add Time to the Week

1. Check the staff record and the Monday–Sunday week.
2. Select **Add Task** and choose the project task or internal task you worked on.
3. Enter hours in the relevant day as decimal hours or `H:MM`. For example, both `1.5` and `1:30` represent an hour and a half.
4. Add a daily note where it helps explain the work. Check the daily billable setting and change it if needed.
5. Check the daily and weekly totals, then select **Save timesheet**. Reopen the week to continue later.

!!! tip "Copy recurring tasks to a new week"

    Copying the previous week brings over the task rows. Enter the new week’s hours and notes separately.

If a project task is missing from **Add Task**, check that you’re entering time for the right staff member and that they’re allocated to the task.

---

## Add a Cost

Select the project and staff member, then enter the date, category, supplier and reference as applicable. Check the quantity and unit cost against the supporting record. Review the recoverable setting separately, then save and check the recorded cost.
