# Adding Contacts and Projects

Open **Clients, contacts and sites** to add a contact or start a shared project record. Search for the client, contact or project first so the team can reuse existing records.

---

## Add a Contact

1. Find and open the client record.
2. Select **Add contact for this client**.
3. Enter the **Contact name** and available **Email** and **Phone** details.
4. Select **Save contact**.

When preparing a proposal, use **Choose a shared contact** to select the saved contact.

---

## Create a Project

1. Open the project creation form and enter the **Project number** and **Project year**.
2. Select the client and add the relevant contact where needed. The form also offers **Create a client** and **Create a contact**.
3. Enter the **Project site / description** and select an existing site record if one applies.
4. Select **Create project**. Open the saved project and confirm the number, client and site before using it in a proposal.

!!! tip "Use the site where the work will happen"

    For the sample kitchen alteration, enter the address of the house being altered. Keep any separate billing address with the client details.
