# Flow Practice Manager Troubleshooting

This page covers common proposal and RFI issues in **Flow Practice Manager**.

For the normal workflow, start with [Preparing a Proposal](preparing-a-proposal.md).

---

## No Matching Projects Are Found

In **Choose a project**, search by project number, client or site.

If Flow shows **No matching projects**, check the project number or try a shorter part of the client or site name.

Select the matching record from the results before choosing **Start proposal**.

---

## The Proposal Shows the Wrong Client or Site

1. Expand **Change project**.
2. Select the correct shared project.
3. Check the project number, client and site before saving the draft.

---

## The Draft Fails to Save

Keep the proposal open and review the message next to **Save draft**.

!!! info "Unsaved edits stay on screen"

    If Flow reports that it couldn’t reach the local database, your edits are still on screen. Keep the page open while the connection is restored.

When the connection is available, select **Save draft** again and wait for the saved confirmation before leaving the page.

---

## An Imported RFI Question Needs Correction

1. Open the imported draft in **Project RFIs**.
2. Compare the question with the original council request. Check its number, subparts and any drawing references.
3. Correct the draft and save the workspace before using the question to prepare a response.

---

## An RFI Response Is Missing from the Library

In **Search library**, clear the **Project** filter and try a shorter search term. If the response still doesn’t appear, open **Project RFIs** and check the source project’s register.

!!! info "Unanswered questions stay in the project register"

    Complete the response and check its text and supporting links before adding the reviewed record to the searchable library.

Save the workspace, then retry the library search.

---

## Reporting a Problem

Include the action you took, the full status or error message, and whether it affects one record or several. If you include a screenshot, obscure client details, site information and fees.
