# Flow Practice Manager Troubleshooting

This page covers common project selection and draft saving issues in **Flow Practice Manager**.

For the normal workflow, start with [Preparing a Proposal](preparing-a-proposal.md).

---

## No Matching Projects Are Found

In **Choose a project**, search by project number, client or site.

If Flow shows **No matching projects**, check the project number or try a shorter part of the client or site name.

Select the matching record from the results before choosing **Start proposal**.

---

## The Proposal Shows the Wrong Client or Site

1. Expand **Change project**.
2. Select the correct shared project.
3. Check the project number, client and site before saving the draft.

---

## The Draft Fails to Save

Keep the proposal open and review the message next to **Save draft**.

!!! info "Unsaved edits stay on screen"

    If Flow reports that it couldn’t reach the local database, your edits are still on screen. Keep the page open while the connection is restored.

When the connection is available, select **Save draft** again and wait for the saved confirmation before leaving the page.
