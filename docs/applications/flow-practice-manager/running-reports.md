# Running Reports

Open **Reports** and choose the view that answers your question.

| View | Use it to |
| --- | --- |
| **WIP & project control** | Review active jobs, stage budgets and forecasts, or follow up work in **Billing review** or **Historical review**. |
| **Staff Project Review** | Review projects a staff member is responsible for or has worked on. |
| **Saved reports** | Find reports already run and review their saved results. |
| **Custom reports** | Choose your own fields, filters and layout, then save the report definition for reuse. |

---

## Build a Report for the Next Team Meeting

1. Open **Custom reports** and choose a project task summary.
2. Select the fields needed to discuss recorded hours and budgets. Choose a table for comparing tasks or a project review pack for reviewing jobs individually.
3. Choose the projects and activity period. For a recurring report, use a rolling period such as **last 90 days**.
4. Preview the report and check that the expected projects and stages appear.
5. Use **Save & run** to keep the definition and generate a saved report. Run it again for the next meeting to apply the period rule to fresh data.

!!! info "Activity dates and fee totals use different scopes"

    The activity period limits hours and costs. Fee and estimate baselines still refer to the whole job. Check these scopes before comparing figures or interpreting a graph.
