# Running Reports

## Choose the Scope

Start with the question you need the report to answer. Use a single project for a job review, a staff filter for work involving a particular person, or a wider date range to review a period across the practice.

## Check the Results

Review the period and filters before sharing the report. If the report includes imported WorkflowMax history, check whether that history is appropriate for the question.

For a stage budget review, check which stages are included and whether the report shows recorded hours, forecast hours, or both.
