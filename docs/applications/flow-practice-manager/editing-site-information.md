# Editing Site Information

Open **Clients, contacts and sites** and find the site by its address or description.

## Update a Site

1. Open the matching record in **Edit site**.
2. Update **Site address / description** and the relevant details.
3. Record where the information came from in **Source / evidence reference**. Complete the verification details once you’ve checked the values.
4. Select **Save site**. If you’re linking the site to a project, select the correct project before choosing **Link site**.

!!! note "Check address lookup results"

    **Find address** can help locate the site. Check the selected address and any imported values before relying on them.
