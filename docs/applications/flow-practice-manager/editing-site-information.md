# Editing Site Information

Open **Clients, contacts and sites** and find the site by its address or description.

## Update a Site

1. Open the matching record in **Edit site**.
2. Update **Site address / description** and the relevant details.
3. Record where the information came from in **Source / evidence reference**. Complete the verification details once you’ve checked the values.
4. Select **Save site**. If you’re linking the site to a project, select the correct project before choosing **Link site**.

---

## Review LINZ Address and Parcel Results

1. Select **Find address** and choose the address that matches the site.
2. Review any property boundary and individual parcel matches. Compare the parcel identifier, legal description and area with your source information before selecting the applicable records.
3. Check which area you intend to save. A property area can cover multiple parcels, so confirm whether the project needs the property area or an individual parcel area.
4. Review the source and verification details, then select **Save site**.
