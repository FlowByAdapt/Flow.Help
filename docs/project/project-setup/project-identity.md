# Project Identity

Project Identity establishes the shared project details used by other
Project Setup workflows.

It is the starting point for both new-project setup and project-folder
planning.

------------------------------------------------------------------------

## Start Here

Open:

**Flow → Project → Setup**

The **Project Identity** card is highlighted when the identity still
requires review and displays **Start here**.

Enter:

-   **Project Year**
-   **Project Number**
-   **Client**
-   **Location**

Then select **Review Identity**.

------------------------------------------------------------------------

## Reviewing the Identity

**Review Identity** validates the entered values before Project Setup
allows dependent workflows to continue.

When the identity is valid:

-   the identity is marked as reviewed;
-   the **Start here** highlight is removed;
-   project-folder planning becomes available; and
-   the reviewed identity can be used by new-project creation.

If the identity is incomplete or invalid, review the message shown in
the Project Identity card and correct the required values.

------------------------------------------------------------------------

## Changing a Reviewed Identity

If **Project Year**, **Project Number**, **Client** or **Location** is
changed after review, Project Setup clears the previous review.

The **Start here** cue returns and the revised identity must be reviewed
again.

!!! warning "Review again after editing"

    A previous review does not remain valid after one of the identity values is changed.

------------------------------------------------------------------------

## Project Identity and Project Information

**Project Identity** and **Project Information** are related but are not
the same thing.

Project Identity contains the shared setup values used by Project Setup
itself.

**Project Information** inspects and edits supported parameters stored
in the active Revit project.

➡️ **[Project Information →](project-information.md)**

------------------------------------------------------------------------

## Project Identity and Project Folders

Project Folder planning uses the reviewed identity to determine the
proposed project folder name and configured target locations.

➡️ **[Project Folders →](project-folders.md)**

------------------------------------------------------------------------

## Project Identity and New Projects

New-project creation requires a valid reviewed identity in addition to a
valid Project Profile and available Revit template.

➡️ **[Creating a New Project →](new-projects.md)**
