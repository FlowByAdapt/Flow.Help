# Existing Building

The Existing Building workflow helps prepare an active Revit project for
an Existing Building model.

It separates preparation into two deliberate operations:

1.  **Cleanup**
2.  **Phasing**

Inspection occurs before either operation changes the project.

------------------------------------------------------------------------

## Opening Existing Building

Open the project, then go to:

**Flow → Project → Setup**

Select **Inspect Project**.

When the Existing Building area reports attention is required, select
**Review / Prepare**.

Opening the review window does not itself delete elements or change
phasing.

------------------------------------------------------------------------

# Cleanup

## What Cleanup Inspects

Cleanup identifies direct targets in three groups:

-   elements with a valid **Phase Demolished** value;
-   **Rooms**; and
-   **Room Separation Lines**.

!!! info "Inspection is read-only"

    Nothing is deleted until you choose **Clean Up** and confirm the action.

------------------------------------------------------------------------

## Clean Up

Select **Clean Up** when the reported targets should be removed.

Flow asks for confirmation before deletion.

!!! warning "Revit may also delete dependent elements"

    The direct cleanup count describes targets identified by Flow.

    Revit can also remove dependent elements, so the final number removed can be greater than the direct target count.

------------------------------------------------------------------------

## Native Revit Deletion Warnings

Revit may display its own deletion warning or error during cleanup where
hosted, inserted, infill or other dependent relationships are involved.

These dialogs are generated by Revit. Review the Revit message before
continuing.

------------------------------------------------------------------------

## After Cleanup

Flow re-inspects Cleanup after execution.

When no direct targets remain, the summary reports that state and
**Clean Up** becomes unavailable.

------------------------------------------------------------------------

# Phasing

## Inspect Phasing

Select **Inspect** in the Phasing card.

Flow inspects applicable elements with a valid **Phase Created** value
and reports:

-   candidate elements;
-   elements remaining outside **Existing**;
-   how many can be updated by Flow;
-   writable candidates; and
-   read-only candidates.

Elements matching the workflow exclusions for **Architrave** and
**Panel** are excluded.

------------------------------------------------------------------------

## Writable and Read-Only Elements

Flow distinguishes writable elements from elements whose phasing is
read-only or controlled by Revit.

**Apply Phasing** is available only when writable elements remain
outside Existing and can be updated by Flow.

------------------------------------------------------------------------

## Apply Phasing

Select **Apply Phasing** to change applicable writable non-target
elements to **Existing**.

Elements already Existing are not rewritten. Read-only elements are not
directly modified.

A confirmation is shown before execution.

------------------------------------------------------------------------

## Revit Phasing Propagation

Revit can propagate phase changes to related or dependent elements.

For this reason, **Directly updated by Flow** can differ from the total
change observed in the model.

Flow reports direct updates separately and then re-inspects the
resulting model state.

------------------------------------------------------------------------

## After Applying Phasing

Flow automatically re-inspects Phasing.

If no writable non-target elements remain, **Apply Phasing** becomes
unavailable.

A remaining element outside Existing does not automatically mean the
operation failed; it may be read-only or controlled by Revit.

------------------------------------------------------------------------

## View Templates

The Existing Building phasing operation changes applicable
`Phase Created` values.

It does not bundle unrelated view-template clearing into the phasing
action.

------------------------------------------------------------------------

## Recommended Workflow

1.  Inspect the current project.
2.  Open **Review / Prepare**.
3.  Review **Cleanup**.
4.  Select **Clean Up** if appropriate.
5.  Review the automatic cleanup reinspection.
6.  Select **Inspect** under **Phasing**.
7.  Review candidate, writable and read-only counts.
8.  Select **Apply Phasing** if actionable elements remain.
9.  Review the automatic phasing reinspection.

------------------------------------------------------------------------
