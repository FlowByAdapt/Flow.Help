# Project Setup

Project Setup provides a guided workflow for creating new Revit projects and reviewing or completing the setup of existing projects.

It brings project configuration tasks together into one coordinated workflow so that office standards can be applied consistently.

---

## Opening Project Setup

On the Revit ribbon, go to:

**Flow → Project → Setup**

---

## What do you want to do?

### 🆕 Create a New Project

Create a project using an approved Flow project profile and the correct template for your version of Revit.

[Creating a New Project →](new-projects.md)

### 🔍 Review a Current Project

Inspect an existing project and identify setup items that are complete, incomplete or require attention.

[Reviewing a Current Project →](current-projects.md)

!!! info "Reviewing a project is safe"

    Project inspection does not automatically change the Revit project.

    Changes are only made when you choose to apply the relevant setup action.

---

## Setup Areas

Project Setup brings several project configuration tasks together.

| Setup area | What it controls |
|---|---|
| **Project Information** | Project number, client, address and other project metadata |
| **Worksets** | Checks and creates the required office-standard worksets |
| **Project Folders** | Checks and provisions the required project folder structure |
| **Templates / Profiles** | Controls the appropriate starting configuration for new projects |
