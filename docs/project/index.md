# Project Panel

The **Project** panel contains tools for creating and configuring Revit projects using Flow project standards.

You can find the Project panel on the **Flow** ribbon in Revit.

---

## Tools

### Project Setup

Create new Revit projects and review or complete the setup of existing projects.

Project Setup provides guided workflows for:

- Project profiles and templates
- Project information
- Project folders
- Worksets

[Project Setup →](project-setup/index.md)

!!! tip "Setting up a project?"

    Use **Project Setup** for both new and existing projects.

    For an existing project, Project Setup can inspect the current configuration and identify items that are complete or require attention.
