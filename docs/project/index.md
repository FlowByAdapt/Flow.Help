# Project Panel

The **Project** panel contains tools for creating, reviewing and configuring Revit projects using Flow project standards.

You can find the Project panel on the **Flow** ribbon in Revit.

---

## Tools

### Project Setup

Create new Revit projects and review or complete the setup of existing projects.

Project Setup brings the main project-startup workflows together in one coordinated tool, including:

- Project Identity
- Project Profiles and Revit templates
- Project Information
- Project Folders
- Worksharing
- Worksets
- Existing Building cleanup and phasing

[Project Setup →](project-setup/index.md)

!!! tip "Setting up a project?"

    Start with **Project Identity** and select **Review Identity** before continuing with workflows that depend on the project details.

    For an existing project, use **Inspect Project** to review the current setup state before applying changes.

!!! info "Inspect before changing"

    Project Setup follows an inspect-first workflow.

    Inspection reports the current project state without automatically changing the Revit model. Changes are only made when you deliberately choose the relevant setup action.
