# Opening Type Catalogues

Use **Type Catalog Manager** to open an existing Revit family type catalogue for review, editing or validation.

---

## Open Type Catalog Manager

On the Revit ribbon:

**Flow → Content → Types**

---

## Open a Type Catalogue

Open the required type catalogue using the available Type Catalog Manager controls.

Once opened, the catalogue can be reviewed within Type Catalog Manager.

!!! info "Opening a catalogue does not change it"

	Opening a type catalogue allows you to review its contents before making any changes.

	Changes are only made when you use the relevant editing or catalogue-management actions.

---

## Review Catalogue Content

Once a catalogue has been opened, review its contents before making changes.

A type catalogue may contain:

* Family types
* Parameter definitions
* Values assigned to individual family types

For more information about reviewing catalogue content, see [**Opening and Reviewing Catalogues**](opening-and-reviewing.md).

!!! tip "Review before editing"

	Check the catalogue contents before making changes, particularly when working with an existing family catalogue.

	You can also use the validation and inspection tools to identify catalogue issues before editing.

---

## Edit the Catalogue

To make changes to the opened catalogue, continue to [**Editing Catalogues**](editing-catalogues.md).

---

## Validate the Catalogue

To inspect the catalogue and check for problems, see [**Validation and Inspection**](validation-and-inspection.md).
