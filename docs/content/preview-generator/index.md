# Preview Generator

The **Preview Generator** creates consistent preview images for Revit content used by Flow and the Revit content library.

Use it to scan a content folder and automatically create missing preview images for supported family and drafting-view content.

---

## Open Preview Generator

On the Revit ribbon:

**Flow → Content → Preview Generator**

Select the content folder you want to process.

Preview Generator searches the selected folder and its subfolders for supported content.

---

## Supported Content

Preview Generator supports:

* Revit family files (`.rfa`).
* Extracted drafting-view container files (`.rvt`).

Existing preview images are skipped automatically, allowing Preview Generator to be run against an existing content library without regenerating every preview.
