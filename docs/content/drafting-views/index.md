# Drafting View Extractor

The **Drafting View Extractor** creates reusable drafting-view content from Revit library files.

Use it to process one or more source RVT files, extract their drafting views into individual Revit files and generate preview images for use within the Flow content library.

---

## Open Drafting View Extractor

On the Revit ribbon:

**Flow → Content → Drafting**

The command is located within the expanded **Content** panel.
