# Content Browser

The **Content Browser** provides a central location for finding, reviewing and loading approved Revit content.

Use it to search the current Revit-version content library, check whether families are already present in the active project, load families or drafting views, and access related content-management utilities.

---

## Open Content Browser

On the Revit ribbon:

**Flow → Content → Browser**

---

## What do you want to do?

### Find Content

Search the library, browse by category, show favourites or recent content, or filter content by its status in the active project.

➡️ [**Browsing and Searching**](browsing-and-searching.md)

### Load Content

Load a family or drafting view directly, choose required types from a type catalogue, or build a queue of content to load together.

➡️ [**Loading Content**](loading-content.md)

### Work with Existing Project Content

Check whether library families are loaded or in use, reload an individual family, or reload groups of project families from the current Flow library.

➡️ [**Project Content**](project-content.md)

### Use Item Actions

Right-click content to open source files and folders, work with previews and type catalogues, extract drafting views, copy the source path, or reload a loaded family.

➡️ [**Content Actions**](content-actions.md)

### Use Content Browser Tools

Open the **Tools** menu for project, family, sheet, drafting-view and library maintenance utilities.

➡️ [**Content Browser Tools**](content-browser-tools.md)

### Having Problems?

Use the troubleshooting checks if content cannot be found, previewed, loaded or reloaded as expected.

➡️ [**Troubleshooting**](troubleshooting.md)

---

## Content Browser at a Glance

The main Content Browser workflow is:

1. Open **Content Browser**.
2. Search or filter the available content.
3. Select an item to review its preview and information.
4. Check its project status if relevant.
5. Load the item directly, add it to the load queue, or use an available right-click action.

The Browser uses the Flow content library for the Revit version currently running.

!!! tip "Use the filters together"

    Category, project status, favourites, recent content and search can be combined to narrow the displayed results.

---

## Main Controls

The Browser includes:

- **Search** — find content using names and indexed content information.
- **Category** — limit results to a library category.
- **Project Status** — show All, Loaded, Not Loaded, In Use or Unused content.
- **Favourites** — show content marked as a favourite.
- **Recent** — show recently loaded content.
- **Load** — load the selected content into the active project.
- **Add To Queue** — add selected content to the load queue.
- **Load Queue** — review and load queued content.
- **Favourite** — add or remove the selected item from favourites.
- **Tools** — open additional Content Browser utilities.
- **Rebuild Index** — rebuild the content-library index.
- **Clear Cache** — clear the local Content Browser cache.

---

## Getting Help

Hover over **Browser** on the Flow ribbon and press **F1** to return directly to this page.
