# Content Panel

The **Content** panel contains tools for finding, managing, upgrading
and creating reusable Revit content and project resources.

You can find the Content panel on the **Flow** ribbon in Revit.

------------------------------------------------------------------------

## Tools

### Content Browser

Browse, search and load standard Revit content.

[Content Browser →](content-browser/index.md)

### Drafting Views

Extract and manage reusable drafting view content.

[Drafting Views →](drafting-views/index.md)

### Preview Generator

Generate preview images for Revit content.

[Preview Generator →](preview-generator/index.md)

### Revit Upgrade

Upgrade Revit content to the current Revit version.

[Revit Upgrade →](revit-upgrade/index.md)

### Type Catalogue Manager

Manage Revit family type catalogues.

[Type Catalogue Manager →](type-catalogue-manager/index.md)

------------------------------------------------------------------------

!!! tip "Working with Revit content?"

    Use the **Content** panel when you need to find, prepare, upgrade or manage reusable Revit content and project resources.

    Each tool provides more detailed guidance for its specific workflow.
