# Assigning Keynotes

Use **Keynotes** to propose office keynote codes for supported family types.

---

## Assign a Code

1. Open **Keynotes**.
2. Search by keynote code or description.
3. Choose the required office keynote from the list.
4. Select the required type rows and choose **Assign Selected**, or choose **Assign All** for all supported types.
5. Review **Current code**, **Proposed code** and **Office description**.

Existing values remain until you explicitly propose a replacement. Use **Keep Selected** to restore the selected types' existing values in the plan.

## Understand Assignment Limits

The tool uses the bundled office keynote catalogue. Arbitrary typed codes are not accepted, and it does not add a missing keynote parameter.

Instance, formula-driven, read-only, internally referenced and office-protected keynote parameters can block assignment. Family type keynotes and material keynotes are separate.

!!! warning "Check the destination project's keynote file"

    Confirm that the project uses the proposed codes and descriptions. Assigning a family keynote does not update the project's keynote file.

---

## Check the Saved Family

Review before-and-after codes in the plan and cleanup report. If types are also renamed, verify the codes under their final names in the cleaned family. Test the intended keynote tags in a project using the correct keynote file.
