# Renaming Types and Parameters

Review proposed English names or enter names manually before saving the cleaned family.

---

## Rename Types

1. Open **Type Names**.
2. Choose **Suggest Type Names** if you want suggestions.
3. Compare **Original Name**, **Proposed English Name** and **Reason**.
4. Edit the proposed names as required.
5. Check that the final names are valid and unique.

!!! tip "Preserve meaningful differences"

    Keep sizes, finishes, product references and model distinctions clear. Naming suggestions need review against the manufacturer's information.

---

## Rename Parameters

1. Open **Parameter Names**.
2. Choose **Suggest Parameter Names** if required.
3. Review **Rename availability** and **Reason**.
4. Edit eligible proposed names.
5. Resolve invalid or conflicting names before saving.

Shared, built-in and formula-referenced names remain protected. Other detected dependencies may also block a rename.

---

## Keep an Existing Name

Leave the proposed name equal to the original name to retain it. Check the final naming plan in **Review** before saving.

!!! warning "Review associated catalogues"

    This workflow does not update an external type catalogue. If the family uses a catalogue, review its type names and parameter headers against the cleaned family before distributing both files.
