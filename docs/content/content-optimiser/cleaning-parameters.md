# Cleaning Parameters

Use **Parameters** to review unwanted metadata and propose changes to eligible family parameters.

---

## Generate a Proposal

1. Audit the family.
2. Open **Parameters**.
3. Choose **Generate Cleanup Proposal**.
4. Review each proposed **Action** and **Proposal reason**.
5. Use **Keep Selected** for information you want to retain.

Generating a proposal updates parameter actions. It does not save the family. Other planned names, keynotes and material choices remain part of the combined plan.

!!! tip "Keep useful manufacturer information"

    Retain product references, certification details and other information your office needs. A suggested cleanup action still needs your review.

---

## Choose Actions Manually

Select the required rows and choose the appropriate action:

| Action | Result |
| --- | --- |
| **Keep Selected** | Retain the parameter and its existing values. |
| **Clear Selected Text** | Blank supported editable text values across the family types while retaining the parameter. |
| **Remove Selected** | Remove an eligible metadata parameter from the whole family. |

Use the parameter search to narrow the displayed rows. Review protection and evidence before applying an action.

!!! warning "Instance defaults and project instances differ"

    Clearing an instance parameter changes the defaults in the cleaned family. It does not clear values on existing instances in your project.

## Protected Parameters

Built-in parameters and parameters with detected internal dependencies are restricted. Formula-driven, reporting, associated and office-protected parameters may be unavailable for cleanup.

Read the row's explanation when an action is blocked. Clearing numeric or Yes/No values to arbitrary defaults is not the text-cleanup workflow.

For shared metadata that is eligible for reviewed cleanup, check external usage before confirming the plan in **Review**.

---

## Review the Result

Choose **Review & Save…** to see the parameter changes alongside the other proposed actions. After saving, inspect retained values, formulas and family behaviour in a test project.
