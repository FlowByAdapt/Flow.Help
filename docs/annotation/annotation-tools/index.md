# Annotation

The **Annotation** tool brings together common Revit documentation workflows for dimensions, tags, text and numbering.

Open **Annotation** from the **Flow** ribbon to access the complete toolset. Individual Annotation workflows may also be available through **Flow Hub** and the **Command Palette**.

---

## Dimensions

### Wall Dimensions

[Wall Dimensions →](wall-dimensions.md)

[Grid Dimensions →](grid-dimensions.md)

## Working with Annotation Tools

Most Annotation workflows interact directly with the active Revit view. Before starting a workflow, open the view containing the elements you want to work with.

Some tools support preselection, while others guide you through selecting elements, points or paths after the workflow starts. The individual Help pages explain the requirements for each tool.

Where a workflow requires Revit model interaction, Flow keeps the Revit canvas available so you can complete the required selection or placement.

!!! tip "Finish interactive workflows with Escape"

	Where a tool asks you to continue selecting or placing elements, press **Esc** when you have finished the interactive sequence.
