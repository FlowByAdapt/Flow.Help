# Annotation

The **Annotation** tool brings together common Revit documentation workflows for dimensions, tags, text and numbering.

Open **Annotation** from the **Flow** ribbon to access the complete toolset. Individual Annotation workflows may also be available through **Flow Hub** and the **Command Palette**.

------------------------------------------------------------------------

## Dimensions

### Wall Dimensions

Create coordinated dimensions for selected walls using Flow dimensioning rules.

[Wall Dimensions →](wall-dimensions.md)

### Grid Dimensions

Create coordinated dimension strings for grids in the active view.

[Grid Dimensions →](grid-dimensions.md)

### Join Dimensions

Join compatible dimension strings into a single continuous dimension while preserving supported dimension labels.

[Join Dimensions →](join-dimensions.md)

### Dimension Labels

Apply dimension-segment labels using room information and supported text workflows.

[Dimension Labels →](dimension-labels.md)

## Working with Annotation Tools

Most Annotation workflows interact directly with the active Revit view. Before starting a command, open the view containing the elements you want to work with.

Where a workflow requires Revit model picking, Flow closes or hides its selection windows so the Revit canvas remains available.

!!! tip "Finish interactive workflows with Escape"

    Where a tool asks you to select elements one by one, press **Esc** when you have finished the selection sequence.
