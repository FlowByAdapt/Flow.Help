# Keynote Manager

The **Keynote Manager** provides a central interface for working with Revit keynote files and the keynote references used by the current project.

Use it to browse and search the keynote hierarchy, add and edit keynote entries, manage project keynote files, review keynote usage, renumber keynote categories and synchronise changed keynote references back into the Revit model.

---

## Open Keynote Manager

On the Revit ribbon:

**Flow → Model → Keynotes**

Keynote Manager opens as a dockable Flow panel and can remain available while you work in Revit.

---

## What do you want to do?

### Work with Keynotes

Browse and search the keynote hierarchy, review used and unused keynotes, add or edit keynote entries, clean categories and reorganise keynote numbering.

➡️ [**Working with Keynotes**](working-with-keynotes.md)

### Work with Project Keynote Files

Open, create, save and manage Revit keynote files, assign a keynote file to the current project, refresh the Revit keynote table and synchronise changed keynote references.

➡️ [**Project Keynote Files**](project-keynote-files.md)

### Having Problems?

Find help if the expected keynote file does not open, a keynote cannot be found, changes cannot be saved, Revit does not show updated keynote information or project references need to be synchronised.

➡️ [**Troubleshooting**](troubleshooting.md)

---

## Keynote Manager and Revit

Keynote Manager works with standard Revit keynote text files.

When a project already has a keynote file assigned through Revit, Keynote Manager can open that file automatically.

Changes made to the keynote file are managed through Keynote Manager, while **Refresh** and **Sync** provide separate workflows for updating Revit where required.

!!! info "Revit remains the keynote host"

	Flow provides additional tools for creating, editing, organising and maintaining keynote information, but the project continues to use Revit's native keynote system.
