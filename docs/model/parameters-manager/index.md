# Parameters Manager

**Parameters Manager** brings together Flow tools for managing opening
Global Parameters, reviewing associations, applying office standards,
and carrying out parameter maintenance.

The current release focuses primarily on **Opening Global Parameters**
used by Flow window and door workflows.

------------------------------------------------------------------------

## Open Parameters Manager

On the Revit ribbon:

**Flow → Content → Parameters Manager**

Parameters Manager opens the **Opening GP Dashboard** and scans the
current model automatically.

------------------------------------------------------------------------

## Opening GP Dashboard

The dashboard provides a quick overview of the Global Parameters
included in the Flow opening workflow.

The summary cards show:

-   **Total GPs** --- all Global Parameters included in the dashboard.
-   **Associated** --- Global Parameters with one or more detected
    associations.
-   **Unused** --- Global Parameters with no detected associations.

Select a summary card to filter the dashboard.

The grid shows:

-   **GP Name**
-   **Type**
-   **Current Value**
-   **Associations**
-   **Status**

Some Global Parameter values can also be edited directly from the
dashboard.

➡️ [**Reviewing Global Parameters**](reviewing-global-parameters.md)

➡️ [**Editing Global Parameter
Values**](editing-global-parameter-values.md)

## Associations

Use the **Associations** tools to inspect or manage Global Parameter
associations on model elements.

-   **Copy GP Setup** --- copy matching GP associations from one source
    element to one or more target elements.
-   **Remove Associations** --- review and remove supported GP
    associations from selected elements.
-   **Review Associations** --- inspect the GP associations on a
    selected element.

➡️ [**Reviewing Associations**](reviewing-associations.md)

➡️ [**Copying GP Setup**](copying-gp-setup.md)

➡️ [**Removing Associations**](removing-associations.md)

## Audit

Use the **Audit** tools to inspect Global Parameter usage.

-   **Refresh Dashboard** --- rescan the current model after parameter
