# Finding Unused Opening GPs

Use **Find Unused Opening GPs** to identify and optionally delete unused
opening Global Parameters.

------------------------------------------------------------------------

## Find Unused Global Parameters

1.  Open **Parameters Manager**.
2.  Expand **Maintenance**.
3.  Select **Find Unused Opening GPs**.
4.  Flow scans the current document.
5.  Review the list of unused opening Global Parameters found.

If none are found, Flow reports that there are no unused opening Global
Parameters.

------------------------------------------------------------------------

## Delete Unused Global Parameters

When unused Global Parameters are found, Flow asks whether you want to
delete them.

The confirmation displays a preview of up to 30 names. If more than 30
are found, Flow also reports how many additional items are included.

Choose **No** to leave them unchanged.

Choose **Yes** to run the cleanup.

After cleanup, the Opening GP Dashboard is refreshed.

!!! warning "Check before deleting"

    Review the listed Global Parameters before confirming deletion.

    This command is intended for unused **opening** Global Parameters, not general project parameter cleanup.
