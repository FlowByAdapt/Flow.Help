# Applying Existing Window Standards

Use **Apply Existing Window Standards** for windows created in the Revit
**Existing** phase.

------------------------------------------------------------------------

## Apply the Setup

1.  Open **Parameters Manager**.
2.  Expand **Setup**.
3.  Select **Apply Existing Window Standards**.
4.  Pick the existing windows you want to process.
5.  Finish the Revit selection.
6.  Flow applies the existing-window GP setup to qualifying windows.

Flow filters the selection to family instances created in the
**Existing** phase.

If no qualifying existing-phase windows are selected, Flow reports this
and no changes are made.
