# Reviewing Associations

Use **Review Associations** to inspect the Global Parameter associations
on a model element.

------------------------------------------------------------------------

## Review an Element

1.  Open **Parameters Manager**.
2.  Expand **Associations**.
3.  Select **Review Associations**.
4.  Pick the element you want to review in Revit.
5.  Review the associations reported by Flow.

Parameters Manager temporarily moves out of the way while you pick the
element.

If the selected element has no Global Parameter associations, Flow
reports that none were found.
