# Auditing Global Parameters

Use **GP Audit** to inspect Global Parameter associations on one or more
model elements.

------------------------------------------------------------------------

## Run an Audit

1.  Open **Parameters Manager**.
2.  Expand **Audit**.
3.  Select **GP Audit**.
4.  Choose whether to audit **multiple elements**.
5.  Pick the required element or elements in Revit.
6.  Review the audit results.

For a single-element audit, pick one element.

For a multiple-element audit, pick the required elements and finish the
Revit selection.

------------------------------------------------------------------------

## Refresh the Dashboard

Use:

**Audit → Refresh Dashboard**

to rescan the current model after parameter or association changes.

The dashboard also performs an initial scan automatically when
Parameters Manager opens.
