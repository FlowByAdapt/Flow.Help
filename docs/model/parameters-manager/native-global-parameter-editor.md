# Native Global Parameter Editor

Use **Open Native GP Editor** when you need Revit's own Global
Parameters interface.

------------------------------------------------------------------------

## Open the Native Editor

Open:

**Parameters Manager → Maintenance → Open Native GP Editor**

Flow attempts to launch Revit's native **Global Parameters** command.

If the current Revit version does not expose the command through the
API, Flow displays an alternative:

-   use the Revit shortcut **GG**, or
-   open **Global Parameters** from Revit's **Manage** tab.

------------------------------------------------------------------------

## When to Use It

The native editor is useful for Global Parameter operations that are not
exposed directly by the Flow dashboard, including values or parameter
types that Flow currently treats as read-only.
