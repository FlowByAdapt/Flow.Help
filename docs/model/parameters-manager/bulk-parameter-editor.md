# Bulk Parameter Editor

!!! info "In development"

    **Bulk Parameter Editor** is a planned extension to Parameters Manager and is not yet available as a completed production workflow.

The intended workflow is to make parameter maintenance across multiple
Revit files easier to review and control from a grid-based interface.

The planned direction includes:

1.  Select Revit files or a source folder.
2.  Scan supported parameter data.
3.  Review the results in a data grid.
4.  Edit proposed parameter values.
5.  Apply selected changes in batch.
6.  Save processed copies for review.

The initial development is expected to focus on type parameters and safe
batch processing before broader parameter support is added.

!!! note "Development status"

    The exact parameter types, file types, filters and editing controls may change as this workflow is developed.

    Use the existing **Fix Keynotes** maintenance workflow for the current batch keynote-standard process.
