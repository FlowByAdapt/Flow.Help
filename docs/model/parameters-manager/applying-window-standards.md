# Applying Window Standards

Use **Apply Window Standards** to apply the standard Flow Global
Parameter setup to supported windows.

------------------------------------------------------------------------

## Start the Workflow

Open:

**Parameters Manager → Setup → Apply Window Standards**

Choose:

-   **Pick Windows**
-   **All Windows**
-   **Cancel**

------------------------------------------------------------------------

## Pick Windows

Choose **Pick Windows** when you want to control which windows are
processed.

1.  Select **Pick Windows**.
2.  Pick the required window elements in Revit.
3.  Finish the selection.
4.  Flow applies the standard window GP setup to the valid selected
    windows.

Curtain-wall-hosted windows are excluded.

------------------------------------------------------------------------

## All Windows

Choose **All Windows** to process valid windows created in the **New
Construction** phase.

Curtain-wall-hosted windows are excluded.

If no valid windows are found, Flow reports this and no setup is
applied.

!!! note "Curtain wall windows"

    Curtain-wall-hosted windows are not included in this workflow.

------------------------------------------------------------------------
