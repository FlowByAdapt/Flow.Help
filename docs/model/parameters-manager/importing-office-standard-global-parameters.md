# Importing Office Standard Global Parameters

Use **Import Office Standard GPs** to bring missing office-standard
Global Parameters into the current project from a selected Revit
template.

------------------------------------------------------------------------

## Start the Import

1.  Open **Parameters Manager**.
2.  Expand **Setup**.
3.  Select **Import Office Standard GPs**.
4.  Select the Revit template containing the office-standard Global
    Parameters.
5.  Flow inspects the source template and compares its Global Parameters
    with the current project.
6.  Continue with the import workflow to add the required missing Global
    Parameters.

Existing Global Parameters with matching names are not intended to be
duplicated.

!!! info "Source template"

    The selected template is used as the source of the office-standard Global Parameters.

    This is different from manually creating arbitrary project, shared or family parameters.
