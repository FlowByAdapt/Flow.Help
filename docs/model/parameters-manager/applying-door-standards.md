# Applying Door Standards

Use **Apply Door Standards** to apply the standard Flow Global Parameter
setup to New Construction doors.

------------------------------------------------------------------------

## Start the Workflow

Open:

**Parameters Manager → Setup → Apply Door Standards**

Choose:

-   **Pick Doors**
-   **All New Construction Doors**
-   **Cancel**

------------------------------------------------------------------------

## Pick Doors

1.  Choose **Pick Doors**.
2.  Pick the required door elements.
3.  Finish the Revit selection.
4.  Flow applies the standard setup to qualifying **New Construction**
    doors from the selection.

------------------------------------------------------------------------

## All New Construction Doors

Choose **All New Construction Doors** to apply the standard setup across
qualifying doors created in the **New Construction** phase.

The current standard includes Global Parameter associations used for
items such as:

-   3D door display
-   interior door trim display
-   architrave depth
-   architrave width
-   plan opening percentage
-   3D panel opening angle

Where required by the standard, Flow uses default architrave values of
**20 mm depth** and **60 mm width**.
