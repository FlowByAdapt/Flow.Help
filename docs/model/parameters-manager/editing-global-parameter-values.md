# Editing Global Parameter Values

Some Global Parameter values can be edited directly from the **Opening
GP Dashboard**.

------------------------------------------------------------------------

## Edit a Value

1.  Open **Parameters Manager**.
2.  Find the required Global Parameter in the dashboard.
3.  Double-click an editable **Current Value** cell.
4.  Enter the new value.
5.  Commit the cell to apply the change through Revit.

Editable values are indicated in the dashboard.

------------------------------------------------------------------------

## Supported Dashboard Editing

The current dashboard supports direct editing for:

-   **Text**
-   **Length / Number**

The following are not currently editable directly from the dashboard:

-   **Integer / Yes-No**
-   **Element**
-   unsupported or unknown value types

The protected **Zero Window Sill Height** Global Parameter is also
read-only in the dashboard.

!!! info "Units"

    Length and number values displayed as lengths are shown in millimetres.

    Global Parameters with **Angle** in their name are displayed in degrees.

------------------------------------------------------------------------

## Other Global Parameter Values

For values that cannot be edited from the Flow dashboard, use Revit's
native Global Parameters editor.

Editor**](native-global-parameter-editor.md)
