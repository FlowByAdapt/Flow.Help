# Copying GP Setup

Use **Copy GP Setup** to copy matching Global Parameter associations
from one source element to one or more target elements.

------------------------------------------------------------------------

## Copy the Setup

1.  Open **Parameters Manager**.
2.  Expand **Associations**.
3.  Select **Copy GP Setup**.
4.  Pick the **source element** that already has the required GP
    associations.
5.  Pick one or more **target elements**.
6.  Finish the Revit selection to continue.
7.  Flow applies the matching GP association setup to the targets.

!!! tip "Choose a suitable source"

    Use an element that already has the Global Parameter setup you want the target elements to follow.

------------------------------------------------------------------------

## What Is Copied

The workflow copies **matching Global Parameter associations**.

It is not a general copy-properties command and does not imply that
every parameter value on the source element is copied.
