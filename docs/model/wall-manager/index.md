# Wall Manager

**Wall Manager** separates supported compound Revit walls into coordinated single- or multi-layer walls and can later recreate the recorded original compound walls.

Use it when a compound wall needs to be divided into independently managed construction layers while preserving its position, constraints, joins and supported hosted doors and windows.

---

## Open Wall Manager

On the Revit ribbon:

**Flow → Model → Walls**

You can also search for **Wall Manager** in Flow Hub.

Wall Manager can be opened from:

- Floor Plans
- Ceiling Plans
- Structural Plans
- 3D views

Other view types are not supported.

!!! info "Supported views"

    Open Wall Manager from a Floor Plan, Ceiling Plan, Structural Plan or 3D view. The tool is intentionally unavailable in other view types.

---

## Typical Workflow

1. Select one or more supported compound walls in Revit.
2. Open **Wall Manager**.
3. Review each wall type and its source layers.
4. Keep layers separate or combine adjacent layers into output groups.
5. Select the output wall that will host doors and windows.
6. Review warnings and the proposed output walls.
7. Click **Separate walls**.
8. Review the new walls, joins and hosted elements in Revit.

Wall Manager records the separation operation so the generated walls can later be selected and recreated as their original compound walls.

➡️ [**Separating Walls**](separating-walls.md)

## Working Set

The **Selected Walls** grid is Wall Manager's current working set.

- **Add selected** adds walls currently selected in Revit.
- **Remove selected** removes the walls currently selected in Revit from the working set.
- **Clear** empties the complete working set without changing the Revit model.

You can therefore keep Wall Manager open, select additional walls in Revit, and add them to the operation.

!!! tip "Keep the window open"

    Select additional walls directly in Revit, then use **Add selected**. You do not need to close and restart Wall Manager to expand the working set.

---

## Layer Groups and Host Wall

The source layers are shown in exterior-to-interior order.

By default, each physical source layer becomes a separate output wall. To combine layers, hold **Ctrl**, select two or more **adjacent** source layers, then choose **Combine selected**.

Non-adjacent layers cannot be combined because a resulting wall must represent a continuous part of the original wall assembly.

Where doors or windows are present, one proposed output wall must be selected as the host.

!!! warning "Check the host before separating"

    The selected host controls where supported doors and windows are rehosted. Confirm the host indicator before applying the separation.

➡️ [**Separating Walls**](separating-walls.md)

---

## Doors, Windows and Global Parameters

Supported wall-hosted doors and windows are rehosted to the selected output wall. Their supported instance values and global parameter associations are preserved.

Where the hosted family contains **Frame Setback**, Wall Manager removes its global parameter association and sets the value to **0.0 mm** for the separated-wall condition.

➡️ [**Hosted Elements**](hosted-elements.md)

---

## Recreating Original Walls

Select one or more walls generated by Wall Manager and choose **Recreate original**. Wall Manager groups the selected generated walls by their recorded separation operation and attempts to restore each original compound wall and its hosted elements.

Recreation uses recorded source data and integrity checks rather than relying only on the current wall joins.

➡️ [**Recreating Original Walls**](recreating-walls.md)

---

## Current Scope

Wall Manager currently supports compound **Basic Walls**.

Curtain walls are not included in the current separation and recreation workflow.
