# Opening Settings

Openings Manager provides settings used by supported opening-management workflows.

---

## Open Openings Manager

On the Revit ribbon:

**Flow → Model → Openings**

---

## Available Settings

> **To verify against the current tool:** Identify the settings currently exposed to the user and their exact UI labels.

Only settings that users can actually configure should be documented here.

---

## Numbering Settings

> **To verify against the current tool:** Confirm whether numbering prefixes, counters, starting values or category-specific numbering behaviour can be configured.

---

## Opening Documentation Settings

> **To verify against the current tool:** Confirm whether view or documentation generation has user-configurable settings.

---

## Apply Settings

> **To verify against the current tool:** Confirm whether settings are applied immediately, require confirmation, and whether they are stored for the project or user.
