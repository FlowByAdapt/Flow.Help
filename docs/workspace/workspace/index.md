# Workspace

Workspace provides tools for saving, restoring and recovering the Revit working environment.

It is designed to make it easier to work across different monitor configurations and to recover Revit or Flow windows that are no longer visible.

---

## Opening Workspace

On the Revit ribbon, go to:

**Flow → Workspace → Workspace**

---

## What can I do?

### Save a Workspace

Save the current arrangement of supported Revit and Flow windows for your current monitor setup.

[Saving a Workspace →](saving-a-workspace.md)

### Restore a Workspace

Return supported Revit and Flow windows to a previously saved arrangement.

[Restoring a Workspace →](restoring-a-workspace.md)

### Manage Saved Workspaces

Update, rename or delete existing workspace layouts.

[Managing Saved Workspaces →](managing-saved-workspaces.md)

### Recover Windows

Bring Revit or Flow windows that have opened outside the visible desktop back onto screen.

[Recovering Windows →](recovering-windows.md)

---

## Restore or Recover?

!!! info "Restore Workspace"

    Use **Restore Workspace** when you want to return to a deliberately saved
    working arrangement, such as your office, home or laptop setup.

    Workspace restores the supported Revit and Flow environment associated
    with that saved layout.

!!! tip "Lost a window?"

    Use **Recover Windows** when a Revit or Flow window has disappeared or
    opened outside the visible desktop.

    You do not need to restore an entire workspace just to recover an
    off-screen window.
