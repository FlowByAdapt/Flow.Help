# Workspace Panel

The **Workspace** panel brings together Flow tools for managing your
Revit working environment, finding and running commands, and controlling
frequently used visibility settings.

You can find the Workspace panel on the **Flow** ribbon in Revit.

------------------------------------------------------------------------

## Tools

### Command Palette

Quickly search for and run Flow tools, supported Revit commands and
indexed library content from a compact floating interface.

[Command Palette →](command-palette/index.md)

### Flow Hub

Use a persistent dockable interface to find and run Flow tools,
supported Revit commands and indexed library content, with quick access
to workspace and visibility controls.

[Flow Hub →](flow-hub/index.md)

### Visibility Manager

Control common project graphics, active-view working aids and
application-level settings from a single interface.

[Visibility Manager →](visibility-manager/index.md)

### Workspace

Save and restore supported Revit and Flow window layouts, manage saved
workspaces and recover windows that have opened outside the visible
desktop.

[Workspace →](workspace/index.md)

------------------------------------------------------------------------

!!! tip "Flow Hub or Command Palette?"

    Use **Flow Hub** when you want a persistent docked interface available while you work.

    Use **Command Palette** when you want a compact floating launcher for quickly finding and running a command or content item.
