# Workspace Panel

The **Workspace** panel contains tools for managing your Revit working environment, accessing Flow commands and controlling common workspace and visibility settings.

You can find the Workspace panel on the **Flow** ribbon in Revit.

---

## Tools

### Workspace

Save and restore Revit workspace layouts, manage saved layouts and recover windows that have opened outside the visible desktop.

[Workspace →](workspace/index.md)

### Flow Hub

Access Flow tools and common workspace functions from a central dockable interface.

[Flow Hub →](flow-hub/index.md)

### Command Palette

Quickly search for and launch Flow tools and commands.

[Command Palette →](command-palette/index.md)

### Visibility Manager

Review and control common project and active-view visibility settings.

[Visibility Manager →](visibility-manager/index.md)

!!! tip "Looking for a Flow tool?"

    Use **Flow Hub** for persistent access to Flow tools while you work, or
    **Command Palette** when you want to quickly search for and launch a command.
